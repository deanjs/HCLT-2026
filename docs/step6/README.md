# step6 — 처방: 값 조향 vs Spotlight

**RQ가 아니다.** RQ1~3의 답에서 도출한 처방이고, 그 답이 옳았는지를 되짚는 검증이다.
step3·step5가 "문제는 Value·후반 단일 층"으로 수렴했으므로 **거기를 밀면 되살아나야 하고,
어텐션을 키우는 기존 접근(Spotlight)은 안 되어야 한다.** 그 예측을 같은 자로 잰 것이 이 스텝이다.
