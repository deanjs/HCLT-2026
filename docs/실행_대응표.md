# 실행 대응표 — 무엇을 돌리면 무엇이 나오나

논문의 표와 그림 하나하나가 **어느 노트북에서 나온 어느 결과를 어느 스크립트로 집계한 것인지**
한 장으로 적은 문서다. 재현하려는 사람이 제일 먼저 볼 곳이다.

절차는 저장소 루트 [`README.md`](../README.md) §재현, 환경은 [`환경_및_버전.md`](환경_및_버전.md)에 있다.

---

## 1. 논문의 표·그림 → 만드는 법

| 논문 | 스크립트 | 읽는 결과 |
|---|---|---|
| **그림 1** (준수율 임계) | `scripts/paper_figures_ko.py` → `docs/step1/figures/ko_cliff.pdf` | `step1_cliff` |
| **그림 2** (지침·코드 어텐션) | 〃 → `docs/step4/figures/ko_attention.pdf` | `step4_instr-observe` |
| **그림 3** (세 경로 순효과) | 〃 → `docs/step3/figures/ko_intervene.pdf` | `step3_code-cause` + `step5_instr-cause(-control)` |
| **그림 4** (조향 세기별 두 채점) | 〃 → `docs/step6/figures/ko_score_vs_real.pdf` | `step6_steer` + `step6_steer-generate` |
| 표 — 선행 코드 순효과 | `scripts/step3_net_effect.py` | `step3_code-cause` |
| 표 — 지침 순효과 | `scripts/step5_net_effect.py` | `step5_instr-cause` + `-control` |
| 표 — 생성 준수율 | `scripts/step6_summary.py` | `step6_steer{,-generate,-crosslayer}` |

그림 4장은 **한 번에** 만들어진다:

```bash
python scripts/paper_figures_ko.py
```

한글 라벨을 쓰므로 나눔 계열 글꼴이 필요하다(`fonts-nanum`).

## 2. 스텝 → 노트북 → 결과 → 집계

노트북은 **모델 하나씩** 돌린다(셀 ③의 `PICK`). 이미 저장된 조건은 건너뛰므로
런타임이 끊기면 같은 노트북을 다시 열면 된다.

### step1 — 문맥의 위반과 준수율의 임계 (RQ1)

| | |
|---|---|
| 노트북 | `notebooks/step1_cliff.ipynb` |
| 결과 | `results/step1_cliff/` 4,368개 |
| 집계 | `scripts/step1_reaggregate.py results/step1_cliff` |
| 논문 | 그림 1 · A1 |

> 접두사 처리가 모델마다 다르다. Qwen2.5-Coder·StableCode는 접두사를 고정하지 않았고,
> DeepSeek-Coder·Llama-3.2는 `"def "`로 고정했다. 논문 한계 절에 명시돼 있다.
> 결과 JSON의 `metrics.extra.forced_prefix`로 조건마다 확인할 수 있다.

### step2 — 코드 신호 관측 (RQ2 관측)

| | |
|---|---|
| 노트북 | `notebooks/step2_code-observe.ipynb` (본실험)<br>`notebooks/step2_position-control.ipynb` (자리 통제, 시드 67) |
| 결과 | `results/step2_code-observe/` 334개 |
| 집계 | `scripts/observe_per_token.py` · `scripts/step2_figures.py` · `scripts/step2_position_control.py` · `scripts/step2_token_bars.py` |
| 논문 | 본문에만 등장 — **주요 결론은 철회했다** |

> 선행 코드 안에서 준수 이름과 위반 이름의 어텐션을 비교하려 했으나 표기 배치가
> 모든 묶음에서 같아 위치 효과가 분리되지 않았다. 배치를 뒤집은 대응 집합에서
> 차이가 사라지거나 방향이 반전되어 근거에서 제외했다. 경위는
> [`step2/results.md`](step2/results.md)에 그대로 남겼다.

| 논문 | 그림 3 왼쪽 · 표 |

### step4 — 지침 관측 (RQ3 관측)

| | |
|---|---|
| 노트북 | `notebooks/step4_instr-observe.ipynb` |
| 결과 | `results/step4_instr-observe/` 336개 |
| 집계 | `scripts/observe_per_token.py` · `scripts/step4_figures.py` · `scripts/step4_direction_control.py` |
| 논문 | 그림 2 |

### step5 — 지침 신호 인과 (RQ3 인과)

**본실험 하나 + 보강 둘**이다. 순서대로 돌린다.

| 순서 | 노트북 | 결과 | 왜 |
|---|---|---|---|
| ① | `step5_instr-cause.ipynb` | `step5_instr-cause/` 336 | 본실험 — 지시어를 반대 표기로 덮어 전 층 스윕 |
| ② | `step5_instr-cause-control.ipynb` | `step5_instr-cause-control/` 2,016 | 통제 — 같은 지시어로 덮어 **덮어쓰기 자체의 효과**를 잰다 |
| ③ | `step5_instr-cause-control-sweep.ipynb` | `step5_control_sweep_*/` 672 | ②를 전 층으로 확장 — 층별 순효과 곡선용 |

| | |
|---|---|
| 집계 | `scripts/step5_net_effect.py` (**논문 표**) · `scripts/step5_reaggregate.py` · `scripts/step5_figures.py` |
| 논문 | 그림 2 세로 파선 · 그림 3 오른쪽 · 표 |

> 논문에 실린 지침 순효과는 **①−③**이다(통제 폴더를 생략하면 `step5_net_effect.py`가
> 전 층 스윕 ③을 자동으로 고른다. ②는 옛 단일 층 실행분이라 쓰지 않는다).
> `step5_reaggregate.py`는 통제를 빼지 않은 원값을 내므로 논문 값과 다르다.

### step6 — 잔차 조향과 어텐션 증폭의 비교 (처방)

**본실험 하나 + 보강 둘**이다.

| 순서 | 노트북 | 결과 | 왜 |
|---|---|---|---|
| ① | `step6_steer.ipynb` | `step6_steer/` 2,184 | 본실험 — 무개입·잔차 조향(최대 효과 층/이른 층)·어텐션 증폭을 선호도로 비교 |
| ② | `step6_verify.ipynb` | `step6_steer-generate/`<br>`step6_steer-crosslayer/` 336 | 실제 이름 생성 + 층 특이성 교차 검증 |
| ③ | `step6_spotlight-generate.ipynb` | `step6_steer-generate/` (합쳐 1,512) | 어텐션 증폭도 실제 생성시켜 같은 자로 비교 |

| | |
|---|---|
| 집계 | `scripts/step6_summary.py` (**논문 표**) · `scripts/fig_score_vs_compliance.py` |
| 논문 | 그림 4 · 표 · A3 |

> ②와 ③이 **같은 결과 폴더에 쓴다.** 잔차 조향만 실제 생성시키고 어텐션 증폭은
> 선호도로만 재면 비교가 성립하지 않기 때문이다.
>
> **묶음 수 주의.** ②·③은 처음에 21묶음으로 돌렸다가 뒤에 나머지 21묶음을 채워
> **42묶음**이 됐다(노트북 셀 ③의 `BLOCKS`). 논문 수치는 42묶음 값이고, 21묶음으로
> 집계하면 DeepSeek α=1이 0.738이 아니라 0.810으로 나온다. 층 대조만 21묶음이다.

## 4. 결과 파일 이름 읽는 법

파일 이름 하나로 조건이 복원된다.

```
qwen2-5-coder-3b-instruct__pre-c0of12-pool-syn-b0__ins-pos-camel-w__int-none__s42.json
└─ 모델 ─────────────────┘  └─ 선행 코드 ───┘  └─ 지침 ──┘  └ 개입 ┘ └시드┘
```

| 조각 | 뜻 |
|---|---|
| `pre-c0of12` | 선행 12개 중 준수 0개 (= 위반 12개) |
| `pool-syn-b0` | 합성 이름 풀, 묶음 0번 |
| `ins-pos-camel-w` | camelCase를 요구하는 긍정형 지침 |
| `int-none` | 개입 없음 |
| `s42` | 시드 42 |

정의는 `src/harness/conditions.py`에 있다.
